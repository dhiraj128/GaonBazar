## How to use
1. Upload all three PNGs and the Markdown prompt to Antigravity in the **same chat**.
2. Tell Antigravity to read all four files together and work **only on its development/preview branches**.
3. The images are conceptual approved layouts. Dynamic names, totals, routes and fake placeholders in drawings are not actual production data. Match visual geometry and design language; maintain existing genuine backend flows.
4. Super Admin is the existing web dashboard. It is specified in the Markdown prompt, not represented by a fourth mobile app image.
5. Do not merge/deploy to production until the owner reviews the visual result and independently verified backups, CI/security and data migration safety gates are satisfied.

**Safety:** Do not send real customer identity documents, bank numbers, login passwords or Aadhaar information in screenshots or public GitHub attachments.
